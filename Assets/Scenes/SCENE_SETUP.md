# Required Screen Flow

1. **Splash / Loading** (`Bootstrap` + splash panel in UIManager)
2. **Main Menu** (Play, settings placeholder)
3. **Character Select** (Male/Female, preview, start run)
4. **Gameplay** (runner, controls, HUD)
5. **Pause Menu** (resume/restart/main menu)
6. **Game Over** (score, best score, restart)

## Transition Map
Splash -> Main Menu -> Character Select -> Gameplay -> (Pause | Game Over)
